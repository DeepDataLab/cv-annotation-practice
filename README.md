# cv-annotation-practice

Hands-on practice in data annotation and computer vision: CVAT, Label Studio, and YOLO object detection, with Python analysis of real datasets and model outputs.

## Projects

- [yolo-object-detection](yolo-object-detection): YOLO detection and tracking on video, and IoU evaluation
- [detection-metrics](detection-metrics): precision, recall and F1 for YOLOv8n against manually labeled ground truth
- [model-assisted-annotation](model-assisted-annotation): reviewing YOLO pre-labels in Label Studio, an independent from-scratch audit, and SQL comparison
